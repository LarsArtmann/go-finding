# go-finding v1.0 Release Criteria

**Date:** 2026-05-07
**Current Version:** 0.2.1

## Release Blockers (Must Resolve Before v1.0)

### API Stability

- [ ] Remove deprecated symbols: `Finding.Tag string` (use `Tags []Tag`), `ConflictDetector`/`Verifier` structs (use package-level functions)
- [ ] Remove phantom `FixStrategyAI` constant (documented as not wired)
- [ ] Finalize `NewFinding` signature — current 6-param is already breaking from 0.1.x, lock it
- [ ] Audit all exported symbols for naming consistency (e.g., `Pos()` vs `NewPosition()`)
- [ ] Decide on `Properties map[string]any` alongside `Metadata` for SARIF fidelity

### Documentation

- [ ] README covers all exported types with examples
- [ ] CHANGELOG updated for v1.0
- [ ] API stability guarantee documented (Go compat promise style)
- [ ] `doc.go` package documentation is comprehensive
- [ ] All examples in `examples/` compile and pass

### Testing

- [ ] Test coverage ≥ 95% (currently 95.8% ✅)
- [ ] All fuzz tests pass (`go test -fuzz`)
- [ ] All property-based tests pass
- [ ] Integration test with downstream consumer (BuildFlow, hierarchical-errors, or branching-flow)

### Pipeline Module

- [ ] Decide domain-specific provider location (inside pipeline/ vs separate)
- [ ] `FixApplier` goroutine leak verified fixed
- [ ] Pipeline.Run() reusability confirmed (was P0 in code review)

## Nice-to-Have (Can Ship Without)

- SARIF schema validation test
- `io.WriterTo` for SARIF output
- Structured logging (slog)
- CLI `run()` testability (io.Writer + *flag.FlagSet)

## Downstream Dependencies (go-finding IS the model)

These projects consume go-finding and will need updates for v1.0:
1. BuildFlow — `finding.Report` in WorkflowResult
2. hierarchical-errors — sealed bridge abstraction
3. branching-flow — SARIF output via go-finding
4. go-structure-linter — analysis adapter
5. golangci-lint-auto-configure — finding integration

## API Surface Lock Checklist

Once v1.0 ships, these become immutable:

### Root Package (finding)
- Types: Finding, Report, Position, Range, Builder, Severity, Confidence, Category, Tag, FixStrategy, Suppression, Correlation, MergeOptions, FilterFunc
- Constructors: NewFinding, NewBuilder, NewReport, Pos, NewRange
- Functions: Filter, GroupBy, Sort, Merge, Correlate
- SARIF: FromSARIF*, ToSARIF*
- LSP: FromLSP, ToLSP*
- JSON: FromJSON*, ToJSON*
- Errors: NewValidationError, NewIOError, etc.

### Pipeline Package
- Types: Pipeline, Config, FixEngine, FixApplier, FixEdit, FixProvider, Detector, FindingProcessor
- Functions: New, DefaultConfig, DetectConflicts, FilterConflictingFixes, Verify

### Analysis Package
- Functions: FromDiagnostic, FromTokenPosition, NodePosition, NodeRange

## Version Strategy

- v1.0.0: Initial stable release
- v1.x.x: Additive changes only (new functions, new types, new options)
- v2.0.0: Breaking changes (if ever needed)
