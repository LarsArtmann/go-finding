# docs/feedback/

**What lives here:** documents that record feedback RECEIVED about this
project from outside it — integration evaluations written in response to
another project's adoption attempt, review notes from external
contributors, and post-mortems of consumer-reported problems. The 2026-06
art-dupl integration evaluation is the canonical example: another tool
tried to consume go-finding and this is the structured verdict.

**What does NOT live here:** this project's own proposals and decisions
(those go to `docs/architecture-decisions.md` and `docs/planning/`),
research (see `docs/research/README.md`), and point-in-time status
(see `docs/status/README.md`).

**Lifecycle:** append-only history. When a feedback item leads to a
decision, the DECISION lives in the ADR log; this directory keeps the
original feedback document untouched, and the ADR links back to it.
