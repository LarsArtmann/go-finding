## d) TOTALLY FUCKED UP

### outputResults signature change cascaded to 8+ test files

Adding `includeSuppressed bool` to `outputResults` broke every test that called it. Required 3 rounds of `sed` + manual fixes across `coverage_extra_test.go`, `integration_output_test.go`, `integration_test.go`, `main_extra_test.go`. Should have used a functional option or a config struct instead of a positional bool parameter — bool params are a known Go anti-pattern because they're unreadable at call sites: `outputResults(w, r, "sarif", true)` — what does `true` mean?

### LSP fuzz test had unused parameters

First version had `endLine, endCol` parameters that were never used. gopls caught it. Should have designed the fuzz corpus to match what I actually test.

### Commit for P07+P08+P09+P10 was a 4-task mega-commit

`39b26ed` lumps SARIF removal + FromDiagnostic refactor + CLI flag + Range method in one commit. These are 4 independent changes that should have been 4 commits. The reason was "they all touch different files" — but that's exactly WHY they should be separate commits.
